### 💡 Sobre o Projeto

Um bot escrito em **JavaScript** utilizando **Discord.js** e **Firebase Real Time DB**, criado para ajudar a comunidade que pratica **roleplay de GTA V no console**.  
Desenvolvido por mim, **Guilherme Cifali**, em aproximadamente **3 semanas corridas no início de 2021**.

A bot written in **JavaScript** using **Discord.js** and **Firebase Real Time DB**, created to assist the **GTA V roleplay console community**.  
Developed by **Guilherme Cifali**, in about **three weeks at the beginning of 2021**.

---

### 🤝 Filosofia do Projeto

- 🚫 **Sem monetização:** sempre foi um projeto livre, criado para compartilhar conhecimento.  
- 🧠 **Aprendizado:** recomendo estudar o funcionamento da **Real Time DB** — há espaço para otimizar o consumo de banda e a arquitetura.  
- 🧩 **Código aberto:** use, aprenda, melhore. Mas mantenha os créditos originais.  
- ❌ **Sem suporte:** este repositório é um registro histórico, não há manutenção ativa.
